🎮 Rock Paper Scissors

A command-line implementation of the classic Rock, Paper, Scissors game built with Python as part of my Data Analytics Bootcamp.

📖 Project Overview

This project was created to practice Python fundamentals by building an interactive game where the user competes against the computer. The game includes score tracking, input validation, replay functionality, and a clean, modular code structure.

✨ Features
🎲 Random computer-generated moves
🏆 First player to reach 3 points wins
✍️ Accepts both full words (rock, paper, scissors) and shortcuts (r, p, s)
✅ Input validation with a limit on invalid attempts
🔄 Play Again option
📊 Live score display after each round
⏳ Delays using time.sleep() for a smoother user experience
🧩 Modular design using reusable functions

🛠️ Technologies
Python 3
Jupyter Notebook
random module
time module
